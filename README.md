# DeepTalk

<!-- keywords: AI Agent, Claude Code alternative, openclaw, MCP, desktop AI, DeepSeek, Kimi, 办公助手, agentic AI -->

> 面向每一个人的 AI Agent 桌面客户端

如果你用过 Claude Code、Cursor、openclaw，你知道 AI Agent 能有多强大——但那些工具是为专业人士设计的。

DeepTalk 做的是同一件事：让 AI Agent 真正替你干活。面向每一个人，不需要任何技术背景。

读文件、改文档、做 PPT、发邮件、截图分析、执行自动化——描述你想做的事，DeepTalk 自动拆解、规划、执行。

运行在本地，数据不离开你的电脑。接入 DeepSeek、Kimi、智谱、Claude、GPT 等任意模型，你的 API Key，你说了算。

## 为什么是 DeepTalk

| | 普通 AI 聊天工具 | DeepTalk |
|---|---|---|
| 能力边界 | 回答问题、生成文本 | 直接操作文件、执行任务 |
| 执行方式 | 给你建议，你去做 | AI 自动规划并执行多步骤任务 |
| 模型绑定 | 固定模型 | 自由接入任意模型 |
| 数据隐私 | 上传至云端 | 全程本地，数据不离开电脑 |
| 扩展性 | 封闭 | 支持 MCP 协议，接入任意工具生态 |

## 核心能力

### 🧠 Plan & Execute — AI Agent 自主执行

AI 不只是回答问题，而是自动拆解任务、制定执行计划、逐步完成。类似 Claude Code、openclaw 的 agentic 执行模式，面向的是所有人的日常工作场景。

### 📂 完整文件系统访问

读写文件、搜索内容、批量编辑文档，AI 直接操作你的本地文件。

### 📊 一句话生成 PPT

描述主题和要点，自动生成结构完整的幻灯片，支持修改和重新排版。

### 📧 邮件起草与发送

直接起草并发送邮件，或存为草稿，支持 SMTP 自定义邮箱配置。

### 🖥️ 系统级自动化

- 截图并分析画面内容
- 执行 macOS 快捷指令（Shortcuts）
- 打开应用、操作剪贴板

### 📄 文档理解

读取 PDF、Word、Excel、TXT 等格式，提取摘要、搜索内容、跨文档关联。

### 🔌 MCP 原生支持

兼容 Model Context Protocol，可接入任意 MCP 服务扩展工具能力，与 Claude Code、openclaw 等工具生态互通。

### 🛡️ 权限确认机制

危险操作（删除文件、发送邮件、执行脚本）前主动询问确认，安全可控。

### ⚡ 技能系统（Skills）

定义可复用的任务模板，固化你的高频工作流，一句话触发。

### 🤖 自由选择模型

支持 DeepSeek、Kimi、智谱 GLM、通义千问、文心一言、OpenAI、Anthropic Claude 等国内外主流服务商，以及任意兼容 OpenAI API 格式的自定义模型。更多服务商持续接入中。
